Decentralized Chat Platform - Technical Overview

Architecture

This decentralized chat platform implements a peer-to-peer network where each user runs a "cell" that acts as both client and server. The architecture includes:

  • Peer-to-Peer Network: Uses WebRTC for direct communication between users
  • Blockchain Storage: Messages are stored in a blockchain-like structure for integrity
  • Local Caching: Each cell maintains a cache of messages for performance
  • Data Sharing: Messages propagate through the network automatically

Key Components

  • User Identification: Each session gets a unique 14-character memorable stamp (e.g., "CleverMonkey1234")
  • Message System: Supports text messages, secret messages, and direct messaging
  • Network Management: Handles peer connections and message routing
  • Cache Management: Implements LRU (Least Recently Used) eviction policy
  • Blockchain: Ensures message integrity with hash-based blocks

Features

  • Decentralized: No central server - each user contributes to the network
  • Resilient: Network continues operating even if individual nodes disappear
  • Secure: Messages are cryptographically secured
  • Independent: No external dependencies - runs entirely in the browser
  • Private: No data collection or tracking

How It Works

  1. When you open the application, a unique stamp is generated for your session
  2. You can set an optional nickname that appears with your messages
  3. Messages you send are added to your local blockchain and cached
  4. Messages propagate to connected peers automatically
  5. When you receive messages, they're added to your local storage and blockchain
  6. The cache helps with performance by storing recent messages locally
  7. Data requests are served by the closest available peer

The Admin Console provides detailed information about the blockchain, message history, and network analysis.
